# Resume

This repository contains my resume as a simple static HTML page.

- **View (GitHub Pages):** https://rishi-kumar-verma.github.io/resume/
- **Open locally:** open [index.html](index.html) in your browser.
- **Download PDF:** there's a download link in the top bar of the page that points to `resume.pdf`. To enable the PDF download, add a `resume.pdf` file at the repository root.

- **Client-side PDF generation:** clicking the "Download PDF" button now generates a PDF in the browser (no server required) using html2pdf.js. If you prefer a committed `resume.pdf` file in the repo, I can generate one and add it.
